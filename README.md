## 🚀 الجديد في الإصدار الثامن (ERP-SYS V8 Highlights)

### 1. فلسفة النظام المتمحور حول المشروع (Project-Centric Architecture)
كل سجل في المنظومة مرتبط بصورة علائقية صارمة بدون أي جداول معزولة:
`Company → Branch → Project → Phase → Zone → Location → WBS → BOQ → Activity → Cost Code → Supplier → Subcontractor → PO → GRN → Invoice`

### 3. دليل المعرفة والتشغيل الموحد للمكتب الفني (KNOWHOW!! Guide)
دليل فني تطبيقي شامل من منظور كبير مهندسي المكتب الفني وحصر الكميات (`knowhow.html` و `view-knowhow`) يغطي 17 قسماً تفصيلياً:
* **دورة حياة المشروع:** المخطط الانسيابي من الترسية إلى الإغلاق المالي.
* **إعداد المشروع من الصفر:** خطوات تهيئة Master Data للشركات والمشاريع ومراكز التكلفة.
* **هيكل WBS القياسي:** 4 مستويات كودية ونسب إنجاز نموذجية.
* **إدارة الـ BOQ:** البنود المركبة، والاستيراد من Excel.
* **حصر الكميات (Takeoff):** مسألة محلولة بالأرقام والخصومات لغرفة (5م × 4م × 3م).
* **تحليل الأسعار (Rate Analysis):** تحليل سعر تفصيلي للخرسانة واللياسة يشمل المواد والعمالة والمعدات والربح والهدر بالريال السعودي.
* **قاعدة الموارد:** توصيفات قياسية للمواد والعمالة والمعدات.
* **الميزانية المعتمدة (CBS):** تجزئة التكاليف وربطها بالـ BOQ.
* **دورة المشتريات:** `MR → RFQ → Comparison → PO → GRN → 3-Way Match → Payment`.
* **عقود الباطن:** القياسات الشهرية، واحتجاز الضمان (Retention 10%)، والمستخلص النهائي.
* **التحكم بالتكلفة (EVM):** القوانين الكاملة ومثال محلول بالأرقام لحالات التجاوز المالي وتوقعات الاكتمال (EAC).
* **منحنيات S-Curve والتقدم:** تقارير DPR والتقدم المخطط مقابل الفعلي.
* **أوامر التغيير وفيديك:** المادة 13 وشرط الـ 28 يوماً للمطالبات وفق المادة 20.1.
* **روتين المكتب الفني الشهري:** خطط عمل أسبوعية لـ (QS, Cost Controller, Planning Engineer).
* **دراسة حالة متكاملة:** مشروع عمارة سكنية (G+3) بقيمة 8.5 مليون ريال من الصفر للتسليم.
* **الأخطاء الشائعة العشرة:** وأفضل الممارسات المهنية لمهندسي المكتب الفني.

### 4. محرك الجدولة الزمنية وحساب المسار الحرج (CPM Engine & Gantt Studio)
* خوارزمية Forward & Backward Pass لحساب تواريخ البدء والانتهاء والمجال الزمني (Total Float & Free Float).
* تحديد المسار الحرج (Critical Path) تلقائياً.
* رسم مخططات جانت (Gantt Chart) تفاعلية عبر لوحة رسم Canvas.
* تصدير بيانات الجدولة بصيغ **Primavera XER** و **MS Project XML**.

### 5. نظام المطابقة الثلاثية في المشتريات (3-Way Matching Engine)
مطابقة تلقائية صارمة بين أمر الشراء (PO)، وإشعار استلام البضاعة (GRN)، وفاتورة المورد قبل السماح بالصرف المالي لحماية الشركة من السداد المزدوج أو التباين في الكميات والأسعار.

### 6. محرك الطباعة والتقارير الرسمية (PrintEngine)
نماذج طباعة معتمدة مصممة وفق لوائح هيئة الزكاة والضريبة والجمارك (ZATCA):
* شهادة الدفع المؤقتة للمقاولين (Interim Payment Certificate - IPC).
* أمر الشراء الرسمي (Purchase Order - PO).
* إشعار المطالبة التعاقدية الرسمية وفق فيديك (Official FIDIC Claim Notice).

### 7. المعمارية النظيفة وفصل الأكواد (Clean Architecture & 100% Separation)
* فصل تام لكافة أكواد التنسيقات (CSS) والبرمجيات (JavaScript) في ملفات خارجية مخصصة.
* خلو كامل لجميع صفحات النظام (index.html, knowhow.html, ومجلدات modules الستة) من أي وسوم `<style>` أو `<script>` مدمجة (Zero Embedded CSS/JS).
* تحسين وقت التحميل والتخزين المؤقت وسهولة الصيانة والمراجعة البرمجية.

### 8. محرك التخزين المزدوج الدائم (Dual Persistence Engine)
حفظ تلقائي للبيانات عبر محرك `MimarEcoStorage` الذي يدمج التخزين في **IndexedDB** و **LocalStorage** لضمان استمرارية الأعمال أوفلاين دون فقدان أي بيانات تشغيلية.

## 🛠️ كيفية التشغيل السريع (Quick Start)

### 1. التشغيل المحلي المباشر:
يمكن فتح النظام مباشرة بدون أي متطلبات إضافية عبر أي متصفح حديث:
* افتح الملف الرئيسي: `index.html`
* أو افتح دليل المكتب الفني: `knowhow.html`
* أو انقر مرتين على ملف التشغيل السريع: `start-erp.bat`

### 2. تشغيل جناح الاختبارات الآلية (Validation Suite):
للتأكد من سلامة النظام وصحة قواعد البيانات والمحركات:
```bash
node scripts/v8_validation.js
```
نتيجة الفحص الحالية: **62/62 Passed بنجاح 100%**.

## 🛡️ معايير الأمان والجودة البرمجية
* **الحماية ضد هجمات XSS:** فحص وتنقية تلقائية لجميع المدخلات وسلاسل النصوص عبر `DOMSanitizer` المدمج.
* **سلامة الروابط:** 0 مسارات مفقودة و 0 مراجع معطلة.
* **فصل التنسيقات والبرمجة:** لا توجد أكواد CSS أو JS مضمنة داخل ملفات HTML مما يتوافق مع معايير CSP (Content Security Policy).
* **التوافق المحاسبي والتعاقدي:** متوافق مع نظام الفاتورة الإلكترونية السعودية (Fatoora) وشروط عقود فيديك 2017.
