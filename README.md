## 🌟 أبرز مميزات المنظومة

### 1. معمارية الحوسبة السحابية متعددة الشركات (Multi-Tenant SaaS)
- **عزل كامل ومستقل للبيانات:** دعم عدد غير محدود من الشركات، الفروع، المشاريع، الموردين، مقاولي الباطن، والعملاء.
- **قاعدة بيانات ديناميكية بنسبة 100%:** انعدام تام لأي بيانات ثابتة (Zero Hardcoding)؛ جميع الكيانات والمسميات والأسعار والحسابات مستمدة لحظياً من سجلات البيانات الأساسية (Master Data).
- **مبدل سياق لحظي (Dynamic Context Switcher):** إمكانية التبديل الفوري بين الشركات والمشاريع والأدوار الوظيفية مع تحديث تلقائي لكافة لوحات التحكم والتقارير.

### 2. محرك المعادلات الرياضية والقواعد الحسابية المعتمدة (682 معادلة نشطة)
- **تغطية حسابية شاملة:** جميع الخلايا والتقارير تحتوي على معادلات Excel ديناميكية تبدأ بـ `=` دون أي قيم ثابتة مضللة.
- **ربط تكاملي متناسق (Referential Integrity):** فحص وتدقيق كافة المفاتيح الأجنبية وعلاقات الجداول بين الـ 14 مصنفاً تخصصياً والمصنف الرئيسي، بدون أي أخطاء من نوع `#REF!` أو `#DIV/0!`.
- **محرك القيمة المكتسبة (EVM Engine):** حساب مباشر لمؤشرات الأداء الجدولية والتكلفية (PV, EV, AC, CV, SV, CPI, SPI, EAC, VAC, TCPI) مع رسم منحنى التدفق التراكمي (S-Curve) مباشرة على الكانفاس.

### 3. دليل الشركاء وكتالوج خامات وأسعار الموردين ومقاولي الباطن (Partner 360°)
دعم كامل لإدارة بيانات الموردين والمقاولين والخدمات والخامات مع الحقول الأساسية:
- **البيانات التعريفية والرقابية:** كود الشريك، الاسم التجاري، الصفة/النوع (مورد / مقاول باطن / استشاري / عميل)، التخصص والتصنيف، الرقم الضريبي (TIN)، السجل التجاري (CR)، مسؤول الاتصال، التقييم، والحالة.
- **المكان والمقر:** المدينة، الحي، والمنطقة الصناعية.
- **المالك / المدير المسؤول:** الممثل النظامي أو المالك المعتمد للتعاقد.
- **كتالوج الخامات والأسعار:**
  - كود وتوصيف الخامة أو البند.
  - الوحدة القياسية والكمية المتفق عليها.
  - السعر الإفرادي قبل الضريبة (SAR).
  - نسبة ضريبة القيمة المضافة ومبلغ الضريبة للوحدة.
  - السعر الإفرادي بعد الضريبة (SAR).
  - إجمالي القيمة قبل الضريبة، إجمالي الضريبة، وإجمالي القيمة شاملة الضريبة (ZATCA 15%).
  - حاسبة تفاعلية للإضافة والتعديل الفوري مع تحديث الكتالوج والمصنفات.

### 4. المكتب الفني وإدارة جداول الكميات والحصر (Technical Office & QS)
- **هيكل تجزئة العمل (WBS) متعدد المستويات:** تقسيم شجري من المستوى 1 إلى 4 متوافق مع تصنيفات CSI MasterFormat.
- **دفاتر الحصر الهندسي التفاعلية (Quantity Takeoff Sheets):** ربط أبعاد الطول والعرض والارتفاع ومطابقة الخصومات مع المخططات المعمارية والإنشائية.
- **تحليل الأسعار التفصيلي (Rate Analysis Recipes):** تجزئة البند إلى مواده الأساسية، نسب الهالك، العمالة، المعدات، ومصاريف الموقع غير المباشرة (Site Overheads).

## 🚀 طريقة التشغيل والبدء السريع

1. **تشغيل الواجهة التفاعلية:**
   - افتح الملف `index.html` مباشرة في أي متصفح حديث (Google Chrome, Edge, Safari, Firefox).
   - لا يتطلب تثبيت خوادم وسيطة بفضل المعمارية الموزعة (Self-contained Client-Side Architecture).

2. **التبديل بين الشركات والمشاريع:**
   - استخدم الشريط العلوي لتغيير الشركة النشطة (مثل: *شركة قمم التشييد للمقاولات* أو *مجموعة البراق للمقاولات*).
   - تتحدث لوحة التحكم فورياً لتعكس عقود وميزانيات وخامات المشروع المحدد.

3. **إدارة كتالوج الخامات والمقاولين:**
   - انتقل إلى تبويب **"دليل الشركاء التجاريين"** من القائمة الجانبية.
   - ستظهر لوحة المؤشرات الإجمالية لكتالوج الخامات مع جدول تفصيلي يربط كل خامة بالمورد وسعرها قبل وبعد الضريبة.
   - اضغط **"إضافة خامة / بند للمورد"** لإدراج خامة جديدة مع الحساب الآلي الفوري لضريبة الـ 15% والقيم التراكمية.

4. **تعديل واستعراض مصنفات Excel:**
   - جميع المصنفات في مجلد `data-workbooks/` ومصنف `Construction-ERP-Data.xlsx` قابلة للفتح عبر Microsoft Excel أو LibreOffice أو Google Sheets.
   - كافة المعادلات مرتبطة وتعمل تلقائياً.

## 🔒 الامتثال والمعايير الهندسية

- **ZATCA Phase 2:** احتساب آلي لضريبة القيمة المضافة 15%، وإعداد الفواتير المتوافقة مع هيئة الزكاة والضريبة والجمارك.
- **FIDIC Red Book:** نماذج الدفعات والمستخلصات الشهرية واحتجاز الضمان (10% Retention) والدفعات المقدمة.
- **PMI EVM Standard:** قياس انحرافات التكلفة والجدول الزمني عبر مؤشرات CPI و SPI ومعادلات التنبؤ عند الاكتمال EAC.
- **ISO 19650 & MasterFormat:** تصنيف بنود الأعمال والوثائق الهندسية وتتبع مراجعات المخططات.
