## 🌟 أبرز مميزات المنظومة وهندسة البيانات المركزية (Master Data Architecture)

### 1. المصدر الموحد للبيانات (Single Source of Truth - SSOT)
- **منع ازدواجية وتكرار البيانات:** تخزين كافة أسعار المواد ومواصفاتها في جدول أسعار مركزي موحد (`02_Supplier_Items`)، مع توليد شيتات الموردين الفردية ومصفوفة المقارنة كـ **Dynamic Array Views** تلقائياً عبر معادلات `FILTER()` و `INDEX/MATCH`، تماماً كأفضل الممارسات المتبعة في SAP S/4HANA وOracle Primavera Unifier.
- **تحديث فوري لأسعار الترسية:** ترتبط دفاتر تحليل الأسعار (Rate Analysis) وأوامر الشراء (POs) مباشرة بالكتالوج المركزي لاختيار أرخص سعر معتمد لحظياً.

### 2. محرك التحليل السعري البارامتري (Parametric Rate Analysis Engine)
- تفكيك وحساب أسعار البنود على مستوى المكونات (خامات، مصنعية، معدات، مقاولو باطن).
- احتساب آلي للمصاريف غير المباشرة (Overheads)، مخاطر الطوارئ (Contingency)، وهامش الربح المستهدف (Target Profit) مع ضريبة القيمة المضافة 15%.

### 3. مركز تقارير ذكاء الأعمال المؤسسي (Enterprise BI Reports Hub)
- **تقرير المصالحة الشهرية (CVR - Cost Value Reconciliation):** مطابقة التكلفة الفعلية (AC) مع الإيراد المعتمد بمستخلصات المالك لتحديد الربح الدفتري وهامش الربحية الفعلي.
- **تقرير القيمة المكتسبة (EVM Performance Dashboard):** مؤشرات CPI, SPI, EAC, VAC, TCPI.
- **تقرير مراقبة المشتريات (Procurement & GRN Variance):** مطابقة ثلاثية 3-Way Matching بين أوامر الشراء والاستلام المخزني والفواتير.
- **تقرير عقود الباطن (Subcontractor Commitments & Retention):** متابعة مستخلصات مقاولي الباطن وحسم محتجز الضمان (10%).
- **تقرير التدفقات النقدية (Project Cash Flow Forecast vs Actual):** المقبوضات والمدفوعات الشهرية والرصيد التراكمي.
- **تقرير مقارنة الموردين (Supplier Price Benchmark & Savings):** تحليل الوفر المالي المتحقق بتطبيق الترسية على أقل سعر معتمد.

### 4. محرك الذكاء الاصطناعي لتصنيف وتسعير البنود (AI Cost Intelligence Matcher)
- **مطابقة معيارية متعددة (Multi-Standard Classification):** مطابقة بنود المقايسة والمواصفات تلقائياً مع 4 أنظمة تصنيف دولية ومحلية معتمدة:
  - **CSI MasterFormat** (الولايات المتحدة / الشرق الأوسط)
  - **DIN 276** (المعايير الألمانية والأوروبية لإدارة تكاليف المباني)
  - **Uniclass 2015** (المعايير البريطانية ونمذجة معلومات البناء BIM)
  - **كود البناء السعودي (Saudi Building Code - SBC)**
- **توليد فوري لدراسات الأسعار:** اقتراح معدلات الأسعار المرجعية التاريخية ونسب الربح والتحويل المباشر بنقرة واحدة إلى جدول الكميات (BOQ) ومحرك التحليل السعري (Rate Analysis).

### 5. عارض نمذجة معلومات البناء والمحاكاة الزمنية (3D BIM Viewer & 4D Time Simulation)
- **محرك إظهار تفاعلي ثلاثي الأبعاد:** محرك إظهار محلي خفيف بتقنية الإسقاط ثلاثي الأبعاد وعناصر IFC لعرض المنشأ الإنشائي (قواعد، أعمدة، أسقف، حوائط، فتحات).
- **التدوير والتحريك والتكبير اللمسي:** دوران ثلاثي الأبعاد حر، تحريك، وتكبير وتصغير مع فحص خصائص أي عنصر هندسي (IFC Tag, Material, Volume, Dimensions).
- **محاكاة 4D Time Phasing:** محاكاة مراحل التنفيذ الزمني (Substructure -> Superstructure -> Envelope -> Finishing -> Complete) بربط زمني ومرئي مع جدول الكميات والمراحل التنفيذية.
- **تصدير الحصر المباشر (QTO to BOQ):** نقل الكميات الهندسية المحسوبة من الموديل ثلاثي الأبعاد مباشرة إلى جداول الحصر ومقايسة المشروع.

### 6. إدارة العمليات الحقلية والموقع (Field Operations Management)
- **اليوميات الموقعية (Site Daily Diary):** تتبع حالة الطقس، عدد ساعات العمل، حصر القوى العاملة الحرفية التراكمي (64 عاملاً عبر 6 أطقم)، ساعات تشغيل المعدات، وتوثيق السلامة المهنية وملاحظات ضبط الجودة اليومية.
- **سجل الملاحظات والعيوب (Punch List / Snagging Register):** مراقبة وتوثيق معالجة ملاحظات الاستلام الابتدائي والنهائي، تصنيف درجة الخطورة (حرجة / متوسطة / ثانوية)، إسنادها لمقاولي الباطن، والاعتماد الفوري بنقرة واحدة.

### 7. إدارة الاستفسارات الهندسية (RFI Management Hub - OpenConstructionERP oe_rfi)
- **دورة طلبات المعلومات الفنية:** تسجيل استفسارات الموقع وربطها بالمخططات التصميمية والمواصفات التعاقدية.
- **تقييم الأثر المالي والزمني (Cost & Schedule Impact):** حصر التأثير المالي لتوجيه الاستشاري وأيام التأخير المحتملة لتغذية مطالبات تمديد الوقت (EOT Claims) وأوامر التغيير.
- **تحديث وإغلاق الاستفسارات:** توثيق الردود الرسمية المعتمدة وتصنيف الأولوية (عاجل، عالي، متوسط).

### 8. سجل اعتمادات المخططات والمواد (Submittals Register - OpenConstructionERP oe_submittals)
- **أكواد الاعتماد التعاقدية (Codes A - D):**
  - **Code A:** معتمد دون ملاحظات (Approved)
  - **Code B:** معتمد مع تدوين الملاحظات (Approved as Noted)
  - **Code C:** مرفوض ومطلوب إعادة التقديم (Revise & Resubmit)
  - **Code D:** مرفوض تماماً (Rejected)
- **تتبع دورة مراجعة الاستشاري:** مخططات الورشة التنفيذية (Shop Drawings)، عينات المواد (Material Samples)، الكتالوجات الفنية (Product Data)، وطرق التنفيذ (Method Statements).

### 9. تفريد حديد التسليح وحساب الهالك (Bar Bending Schedule BBS - OpenConstructionERP oe_rebar_schedule)
- **محرك الحساب الهندسي:** احتساب أوزان الأسياخ بدقة الكود ($D^2/162 \text{ kg/m}$) للأقطار من Ø8 إلى Ø32 مم.
- **أشكال التفريد وأطوال التقطيع:** حصر كود الشكل (Straight, L-Bend, U-Shape, Stirrups كانات)، أطوال التقطيع، والوزن الإجمالي بالأطنان.
- **إدارة هالك الحديد التجاري (Scrap Allowance):** تقدير نسبة الهالك (3% - 5%) لحساب كميات الشراء الإجمالية بالأسياخ القياسية (12 متراً).
- **حاسبة تفاعلية وتصدير فوري:** حاسبة سريعة للأوزان والتكاليف وتصدير مباشر لجدول التفريد بصيغة Excel / CSV.

### 10. حزمة الشرق الأوسط والخليج العربي (Middle East & GCC Regional Pack - oe_middle_east_pack)
- **الأنظمة الضريبية والفوترة الإلكترونية:** دعم تخصيص السعودية (15% ZATCA Phase 2)، الإمارات (5% EmaraTax)، البحرين (10%)، عمان (5%)، مصر (14% الفاتورة الإلكترونية ETA)، قطر والكويت (0%).
- **تنظيم ساعات عمل رمضان المبارك:** خفض ساعات العمل اليومية تلقائياً إلى 6 ساعات بدلاً من 8 ساعات بموجب نظام العمل السعودي م98 والمرسوم الإماراتي 33/2021.
- **التقويم المزدوج والمعايير الإقليمية:** دعم التقويم الهجري والميلادي، ومطابقة معايير CESMM4 و POMI و ICMS وكود البناء السعودي (SBC) وعقود الفيديك (FIDIC Red/Yellow/Silver).

### 11. مركز فحص وتنسيق التعارضات الهندسية (BIM Clash Detection Hub - oe_clash)
- **رصد التداخلات المكانية (Hard & Clearance Clashes):** كشف التعارضات المباشرة بين التخصصات (إنشائي، ميكانيك HVAC، سباكة، كهرباء) مع حساب مسافة التداخل بدقة.
- **إدارة دورة الحل والتنسيق (BCF Coordination):** توثيق الحلول المعتمدة وربطها التلقائي بطلبات المعلومات (RFIs) ومخططات الورشة مع اعتماد الحل بنقرة واحدة.

### 12. إدارة أوامر التغيير والمطالبات المالية (Change Orders & Variations - oe_changeorders)
- **حوكمة التعديلات التعاقدية (FIDIC Sub-Clause 13.3):** تسجيل أوامر التغيير الصادرة من المالك أو المقاول، وحساب الأثر المالي الصافي وتمديد الوقت المعتمد (EOT Days).
- **التحديث التراكمي لقيمة العقد:** إعادة حساب القيمة التعاقدية المعدلة آلياً والمطابقة الفورية مع موازنة المشروع ودفاتر الـ CVR.

### 13. محرك حفظ واستعادة البيانات محلياً (Client-Side LocalStorage Persistence)
- حفظ فوري وتلقائي لكافة الإضافات والتعديلات والاعتمادات على المتصفح محلياً دون الحاجة لقواعد بيانات سحابية، لضمان استمرارية العمل دون فقدان البيانات عند إعادة التحميل.

### 14. التصدير الفوري لجداول النظام (Instant Excel / CSV Export)
- زر تصدير مباشر في الشريط العلوي يدعم تصدير أي جدول معروض إلى ملف متوافق كلياً مع Microsoft Excel بترميز UTF-8 BOM المعتمد للغة العربية دون أي مشاكل ترميز.

## 🚀 طريقة التشغيل المحلي (Offline - Local Mode)

> **النظام يعمل بالكامل بدون إنترنت** — جميع الخطوط والأيقونات محفوظة محلياً.

### الطريقة الأولى: تشغيل بنقرة واحدة ✅ (موصى بها)
```
انقر مرتين على: start-erp.bat
```
يقوم الملف تلقائياً بتشغيل خادم Python محلي على المنفذ **8080** ويفتح النظام في المتصفح.

### الطريقة الثانية: تشغيل مباشر
```
افتح مباشرة: index.html
في أي متصفح حديث (Chrome, Edge, Firefox)
```

### الطريقة الثالثة: خادم Python يدوي
```bash
cd "D:\ERP sys"
python -m http.server 8080
# ثم افتح: http://localhost:8080
```
